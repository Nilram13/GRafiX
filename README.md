# GrafiX

GrafiX is a tiny “Processing-like” 2D drawing library (C++20) built on top of SFML.

You write code like `gfx::circle(...)`, `gfx::rect(...)`, `gfx::text(...)` and run it with `gfx::run(setup, draw)`.

## Quick Start (English)

Detailed Instructions Below.

1) Install **Visual Studio 2022** and select **Desktop development with C++**.  
2) Download this repo as a ZIP, extract it into your CLion projects folder, and rename it from `GrafiX-main` to `GrafiX`.  
3) Open the folder in **CLion**, select **Ninja** and the **Visual Studio** toolchain, let CMake configure, then build target **`GrafiX`**.  
4) Run the demo target to test.

After that, you can use GrafiX from another project via the included consumer example (see links below).

---

## Schnellstart (Deutsch)

Ausführliche Anleitung unten.

1) Installiere **Visual Studio 2022** und wähle **Desktopentwicklung mit C++**.  
2) Lade dieses Repo als ZIP herunter, entzippe es in deinen CLion-Projekte-Ordner und benenne es von `GrafiX-main` in `GrafiX` um.  
3) Öffne den Ordner in **CLion**, wähle **Ninja** und die **Visual Studio** Toolchain, lass CMake durchlaufen und baue das Target **`GrafiX`**.  
4) Starte das Demo-Target zum Testen.

Danach kannst du GrafiX in einem anderen Projekt nutzen (siehe Links unten).
